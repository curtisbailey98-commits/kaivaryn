# Integration guide sources

Public documentation used to author Kaivaryn's per-system integration guides.
Where a specific menu path or capability couldn't be confirmed, the guide says
"confirmed with your Kaivaryn lead during setup". Kaivaryn never claims an
approved partner or marketplace app with any vendor.
